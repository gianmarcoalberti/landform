# landform: Topographic Position Index-Based Landform Classification

Classifies a landscape into slope-position or landform classes on the
basis of the Topographic Position Index (TPI) and slope (Weiss 2001;
Jenness 2006).

## Details

Main functions:

- [`landform`](landform.md): Slope Position and Landform
  classifications, returned as an object with `print`, `summary` and
  `plot` methods;

- [`tpi`](tpi.md): the TPI surface itself, raw or standardised;

- [`class_layers`](class_layers.md): one presence/absence layer per
  class;

- [`malta_dtm`](malta_dtm.md): a sample digital terrain model.

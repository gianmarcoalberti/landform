# Package index

## Classification

Classify a DTM into slope-position or landform classes; the result is an
object with print(), summary() and plot() methods.

- [`landform()`](https://gianmarcoalberti.github.io/landform/reference/landform.md)
  : Landform Classification
- [`plot(`*`<landform>`*`)`](https://gianmarcoalberti.github.io/landform/reference/plot.landform.md)
  : Plot a landform classification
- [`class_layers()`](https://gianmarcoalberti.github.io/landform/reference/class_layers.md)
  : One layer per class

## Topographic Position Index

The TPI surface on which the classifications are based.

- [`tpi()`](https://gianmarcoalberti.github.io/landform/reference/tpi.md)
  : Topographic Position Index

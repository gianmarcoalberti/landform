# Package index

## Classification

Classify a DTM into slope-position or landform classes; the result is an
object with print(), summary() and plot() methods.

- [`landform()`](landform.md) : Landform Classification
- [`plot(`*`<landform>`*`)`](plot.landform.md) : Plot a landform
  classification
- [`class_layers()`](class_layers.md) : One layer per class

## Topographic Position Index

The TPI surface on which the classifications are based.

- [`tpi()`](tpi.md) : Topographic Position Index

## Sample data

- [`malta_dtm()`](malta_dtm.md) : Sample digital terrain model of Malta
